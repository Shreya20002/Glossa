## Root: the app's build and tooling

An Electron app is like a website bundled with its own Chrome browser, plus a
Node.js "back end" with access to the computer. These files configure how it
all gets installed, checked, built and packaged.

| File                                       | What it is                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | When you'd touch it                                                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `package.json`                             | The project's ID card: name, version, license, **scripts** (`pnpm dev`, `pnpm check`…) and **dependencies**. `dependencies` (onnxruntime-node and transformers.js) ship inside the app; `devDependencies` are build and test tools. `packageManager` pins the exact pnpm version: pnpm switches to it automatically, and so does CI. Under `pnpm`: `overrides` swaps the `sharp` image library for Glossa's stand-in (see `stubs/sharp/README.md`), and `ignoredBuiltDependencies` lists packages whose install scripts we deliberately skip (`electron-winstaller`: an installer format we don't use; `onnxruntime-node`: only downloads optional NVIDIA GPU files; `protobufjs`: only prints version warnings). | Adding scripts or dependencies (use `pnpm add`, not hand edits). Never change `version` by hand; the release tool does it. |
| `pnpm-lock.yaml`                           | Generated by pnpm: the **exact** version of every package (including dependencies of dependencies), so everyone, and CI, installs identical code.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Never by hand. Commit it whenever `pnpm install` changes it.                                                               |
| `tsconfig.json`                            | Root TypeScript config. It only points to the two configs below.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Rarely.                                                                                                                    |
| `tsconfig.base.json`                       | Shared TypeScript settings, mostly strictness options that catch bugs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Rarely.                                                                                                                    |
| `tsconfig.node.json`                       | Type-checks code that runs in **Node.js** (main process, preload, config files).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | When adding a new Node-side folder.                                                                                        |
| `tsconfig.web.json`                        | Type-checks code that runs in a **window** (browser APIs + React, no Node).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | When adding a new window-side folder.                                                                                      |
| `tsconfig.e2e.json`                        | Type-checks the end-to-end tests. They run in Node.js but also send code into Glossa's windows, so they need both sets of types. Kept separate so browser types never leak into main-process code.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                | Rarely.                                                                                                                    |
| `electron.vite.config.ts`                  | How electron-vite builds everything: the main process **and the engine** (two entries), the preload script, and one HTML page per window (`app`, `overlay`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | When adding a new window or process.                                                                                       |
| `vitest.config.mts`                        | Unit-test settings: tests are `src/**/*.test.ts`, next to the code they test.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Rarely.                                                                                                                    |
| `playwright.config.ts`                     | End-to-end test settings: tests live in `e2e/`, run one at a time (Glossa allows a single running copy), with one retry in CI.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Rarely.                                                                                                                    |
| `eslint.config.mjs`                        | Lint rules, including Glossa's custom guards: **no network code in `src/`** and **no impure imports in `src/core/`**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | When a rule is wrong or a new guard is needed.                                                                             |
| `electron-builder.yml`                     | How the compiled app becomes a Windows `.exe` / macOS `.dmg`. It packs only `out/` and the runtime packages, bundles `models/` as resources, keeps onnxruntime's native files outside the archive (`asarUnpack`), keeps only this platform's onnxruntime binaries and Chromium's English files, points to the app icons, signs the Mac app ad hoc, and sets the macOS microphone-permission text. `appId` is the app's permanent identity.                                                                                                                                                                                                                                                                        | When a new native package needs unpacking or trimming.                                                                     |
| `build/icon.svg`                           | The **app icon**'s source: a speech bubble with voice-level bars on Glossa's blue tile, laid out on the macOS icon grid. Editable in any text editor, or in Inkscape.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | To change the icon; then run `pnpm icon`.                                                                                  |
| `build/icon.png`, `build/icon-windows.png` | The icons electron-builder packs, drawn from the SVG by `pnpm icon`: with the margin and shadow macOS expects, and filling the square for Windows. The only image files in the repo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Never by hand: run `pnpm icon`.                                                                                            |
| `release-please-config.json`               | Settings for **release-please**, the robot that versions releases: the first version (1.0.0) and the tag format (`v1.0.0`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Rarely ([chapter 05](05-releasing.md)).                                                                                    |
| `.release-please-manifest.json`            | Where release-please remembers the current version.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Never by hand.                                                                                                             |

**Why `src/core` is checked by both tsconfigs:** the Node config has no browser
APIs and the web config has no Node APIs. Code that compiles under _both_ can
only use plain JavaScript, which is exactly what "pure core" means.

**Why there's no `onlyBuiltDependencies: ["electron"]`** (the plan mentioned
it): Electron 44 no longer runs an install script. It downloads its program the
first time something uses it, so there's nothing for pnpm to allow.

## `src/`: the app itself

Electron runs Glossa as separate **processes** that can't see each other's
memory. They talk by sending messages (**IPC**, inter-process communication).
[docs/architecture.md](../architecture.md) follows one chunk of audio through
all of them.

```
window (web page, sandboxed) ◄── preload ──► main process (full access) ◄──► engine (AI models)
src/renderer/                    src/preload/  src/main/                       src/engine/
```

| File                                    | What it is                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/main/index.ts`                     | Entry point of the **main process**: applies the security rules, creates the engine host and session controller, registers IPC handlers, opens the window. Only one copy of Glossa can run at a time.                                                                                                                                                                                |
| `src/main/windows.ts`                   | Creates the app window (kept at full speed when minimized, because it captures the mic) and the **overlay**: frameless, transparent, always on top (even over full-screen apps), and hidden from screen sharing where the OS supports it.                                                                                                                                            |
| `src/main/session.ts`                   | The **session controller**: start (check models → macOS mic permission → engine ready → open overlay), forward audio, stop, save the session to the history, and send every window its report card (or why the session ended early).                                                                                                                                                 |
| `src/main/engine.ts`                    | Starts the engine as a hidden **utility process**, sends it messages, and waits for replies with a timeout. `modelsDir()` finds the models in development or in the installed app.                                                                                                                                                                                                   |
| `src/main/permissions.ts`               | Asks macOS for microphone access (once). Skipped for the fake microphone in tests.                                                                                                                                                                                                                                                                                                   |
| `src/main/security.ts`                  | The security baseline: blocks every network request, grants only microphone access and only to Glossa pages, stops navigation, new windows and webviews, and checks who sent each IPC message.                                                                                                                                                                                       |
| `src/main/security.test.ts`             | Tests for the URL and permission rules: internet blocked, camera never allowed, other sites denied.                                                                                                                                                                                                                                                                                  |
| `src/main/ipc.ts`                       | Handlers for messages from windows: app version, start/stop session, incoming audio (dropped silently if it has the wrong type or size, or comes from an unknown sender), the latest report card, and copying the card as an image.                                                                                                                                                  |
| `src/main/history.ts`                   | The **session history**: `sessions.jsonl` in the app's data folder, one line per saved session. Adds lines, reads recent ones back (skipping damaged lines) and builds the latest report card. If someone asks how to reset their history: delete that file. Tests in `history.test.ts`.                                                                                             |
| `src/main/captureArea.ts`               | Checks the area a page asks to copy as an image (the report card) and keeps it inside that window. Tests in `captureArea.test.ts`.                                                                                                                                                                                                                                                   |
| `src/engine/index.ts`                   | Entry point of the **engine**: receives audio, runs each frame through the VAD model and `src/core`, and sends live metrics back four times a second. Handles requests strictly in order.                                                                                                                                                                                            |
| `src/engine/sileroVad.ts`               | Runs the **Silero VAD** model with onnxruntime: give it 32 ms of audio, get back how likely it is to be speech. Carries the model's memory from frame to frame.                                                                                                                                                                                                                      |
| `src/engine/speechRecognizer.ts`        | Runs the **Whisper tiny.en** speech recognizer through transformers.js: give it a phrase of speech, get back text. Loads from disk only, and uses one CPU thread (as fast as more, and kinder to the meeting app).                                                                                                                                                                   |
| `src/engine/transcription.ts`           | How much padding goes around each phrase before transcription. Shared by the engine and the benchmark so they can't drift apart.                                                                                                                                                                                                                                                     |
| `src/engine/frameBuffer.ts`             | Cuts audio chunks of any length into exact 512-sample frames (tests in `frameBuffer.test.ts`).                                                                                                                                                                                                                                                                                       |
| `src/engine/audioHistory.ts`            | Remembers the last 30 seconds of audio (older audio is overwritten), so a finished phrase can be cut out and transcribed. Tests in `audioHistory.test.ts`.                                                                                                                                                                                                                           |
| `src/preload/index.ts`                  | The **bridge**. Exposes a small, fixed API as `window.glossa`: version, start/stop, push audio, subscribe to metrics and session end. Pages can call only these functions, never Electron directly.                                                                                                                                                                                  |
| `src/shared/ipc.ts`                     | Channel names and the `window.glossa` API shape, imported by main, preload and renderer so all three always agree.                                                                                                                                                                                                                                                                   |
| `src/shared/engine.ts`                  | The messages between the main process and the engine.                                                                                                                                                                                                                                                                                                                                |
| `src/shared/models.ts`                  | Model file names (must match `scripts/fetch-models.mjs`).                                                                                                                                                                                                                                                                                                                            |
| `src/renderer/env.d.ts`                 | Tells TypeScript that `window.glossa` exists and what it looks like.                                                                                                                                                                                                                                                                                                                 |
| `src/renderer/audio/microphone.ts`      | Opens the microphone at 16 kHz, connects the worklet, and turns browser microphone errors into advice people can act on.                                                                                                                                                                                                                                                             |
| `src/renderer/audio/capture.worklet.ts` | Runs on the browser's **real-time audio thread**: collects samples into 32 ms chunks and hands them to the page.                                                                                                                                                                                                                                                                     |
| `src/renderer/app/`                     | The app window: `App.tsx` (microphone picker, Start/Stop, live numbers, and the report card or, before the first session, the feature list), `ReportCard.tsx` (the card and its _Copy as image_ button), `FillerTrend.tsx` (the trend sparkline), `useMicrophones.ts` (lists microphones, remembers your choice), `index.html` (with the **Content Security Policy**) and `app.css`. |
| `src/renderer/overlay/`                 | The floating pill: speaking dot, talk %, pace, fillers, elapsed time and a stop button. It pulses gently during a monologue. Display only: it never touches audio.                                                                                                                                                                                                                   |
| `src/core/voiceActivity.ts`             | Turns per-frame speech probabilities into clean speech start/end events (two thresholds, a minimum speech length, a silence hangover).                                                                                                                                                                                                                                               |
| `src/core/talkTime.ts`                  | Adds up speaking time and computes the talk ratio.                                                                                                                                                                                                                                                                                                                                   |
| `src/core/session.ts`                   | Combines everything into a session you drive one frame at a time: talk time, turns, phrases ready to transcribe, pace once word counts come back, the live metrics, and the end-of-session summary.                                                                                                                                                                                  |
| `src/core/speechChunks.ts`              | Groups speech into **phrases** for Whisper: a 2 s pause ends one, long ones close at the next pause after 12 s, and anything with under 1 s of speech is skipped (that's where Whisper invents words).                                                                                                                                                                               |
| `src/core/pace.ts`                      | **Pace**: words ÷ time spent saying them over the last minute, with the slow (<110) and fast (>170 wpm) thresholds.                                                                                                                                                                                                                                                                  |
| `src/core/words.ts`                     | Counts words in a transcript ("don't", "2,000" and "um" are one word each).                                                                                                                                                                                                                                                                                                          |
| `src/core/fillers.ts`                   | The **filler rules**: um/uh/er… always; "like", "you know", "I mean", "kind of" only in filler positions (using Whisper's punctuation). Also the totals, per-minute rate and top fillers.                                                                                                                                                                                            |
| `src/core/transcript.ts`                | Turns a transcript into **counts** (words and fillers) and drops the text. Contains the safety nets: removing Whisper's repetition loops, and ignoring impossibly dense transcripts.                                                                                                                                                                                                 |
| `src/core/monologue.ts`                 | **Turns** and the **monologue alert**: a pause of 2 s or more ends a turn, and a turn over a minute is a monologue (the overlay pulses until you pause). Also remembers the longest turn and how many went over a minute.                                                                                                                                                            |
| `src/core/report.ts`                    | The **report card**: compares a session with the previous saved one (better or worse only where there's a right direction: fewer fillers, pace towards 110–170 wpm, turns under a minute), builds the filler trend over the last 10 sessions, and sets the 5-second minimum for saving.                                                                                              |
| `src/core/sessionRecord.ts`             | How a session is saved as one line of JSON, and the strict check when reading it back (the file could be damaged or edited).                                                                                                                                                                                                                                                         |
| `src/core/format.ts`                    | Formats durations (`1:05`), session lengths (`32 min`) and percentages (`68%`) for display.                                                                                                                                                                                                                                                                                          |
| `src/core/*.test.ts`                    | Unit tests for all of the above, including edge cases like NaN, duplicate events and blips shorter than a word.                                                                                                                                                                                                                                                                      |

**Defense in depth:** the network is blocked three times. The page's CSP
refuses outside connections, `security.ts` cancels any request that slips
through, and ESLint rejects network code before it's ever merged.

## `scripts/`, `e2e/` and `models/`

| Path                                                             | What it is                                                                                                                                                                                                                                                                                                        |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `scripts/fetch-models.mjs`                                       | Downloads each AI model from a pinned commit and checks its **SHA-256 fingerprint**, so a changed or tampered file is rejected. The only network code in the project, and it never runs inside the app.                                                                                                           |
| `scripts/render-icon.mjs`                                        | Draws `build/icon.svg` into the two PNG app icons with Electron's own Chromium (`pnpm icon`), so no image library is needed.                                                                                                                                                                                      |
| `e2e/session.spec.ts`                                            | The end-to-end test: start a session, check that the speaking dot lights up and goes out, that talk time, pace and fillers are sensible, and that short sentences don't trigger the monologue alert; stop and check the report card, copy it as an image, then restart Glossa and check the card is still there.  |
| `e2e/support/speechClip.ts`                                      | Makes the test recording with the OS's own text-to-speech (Windows SAPI or macOS `say`): 2.5 seconds of silence (while the fake microphone settles), then two sentences with 4-second pauses. Generated fresh each run, never committed.                                                                          |
| `e2e/support/launch.ts`                                          | Starts Glossa with a fresh data folder (so tests never touch your own history) and, for a session, Chromium's **fake microphone** playing that clip: either the dev build or, with `GLOSSA_E2E_PACKAGED=1`, the packaged app. On macOS it also lets Chromium's sandboxed audio process read the clip (test only). |
| `e2e/support/diagnostics.ts`, `wav.ts`, `publishDiagnostics.mjs` | Self-diagnosis: when the test fails (or always, with `GLOSSA_E2E_DIAGNOSTICS=1`), it reports the clip's format, each window's text, a direct measurement of the fake microphone, and Chromium's audio warnings. In CI the report is posted as a public annotation.                                                |
| `models/`                                                        | Downloaded models. **Not in git** (see `.gitignore`); run `pnpm fetch-models` to get them.                                                                                                                                                                                                                        |
| `stubs/sharp/`                                                   | A 5-line **stand-in** for the `sharp` image library. transformers.js refuses to start without sharp, but Glossa never touches images, so this replaces about 20 MB of native code. Its README explains how to remove it.                                                                                          |
| `eval/`                                                          | The **accuracy benchmark** (`pnpm eval`): `clips.json` lists clips of real meetings (AMI Meeting Corpus, CC BY 4.0) with human transcripts; `fillers.eval.ts` runs the real pipeline over them and prints recall and precision. Audio downloads to `eval/.data/` (git-ignored). Explained in `eval/README.md`.    |
